## What Interests Me

- **Delivery pipelines** with explicit build, test, and deployment steps.
- **Environment consistency** that makes applications easier to run and troubleshoot.
- **Operational automation** that turns recurring tasks into repeatable procedures.
- **Observability** that helps explain failures, performance changes, and service health.
- **Recovery workflows** with clear checks and documented next steps.

## Development Priorities

- Make setup steps and environment assumptions explicit.
- Start with a small, repeatable workflow before adding complexity.
- Check failure paths and recovery steps alongside successful runs.
- Keep credentials separate from source code and routine output.
- Document verification steps so someone else can understand the result.
